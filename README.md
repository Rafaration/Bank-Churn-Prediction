# Bank Churn Prediction 🏦📊

## 📌 About the Project
This repository contains a Machine Learning model focused on predicting bank customer churn. Identifying in advance which customers are likely to leave the bank allows for proactive retention strategies. The model was trained using the **CatBoost** algorithm.

## 📂 Repository Structure

Based on the project's organization, the files are structured as follows:

* **`bank-customer-churn-ict-u-ai/`**: Folder containing the main project files and datasets.
  * **`ChurnModel.ipynb`**: Original Jupyter Notebook for data analysis and modeling.
  * **`previsoes_churn.csv`**: Final generated file containing the churn predictions.
  * **`sample_submission.csv`**: Example file showing the expected submission format.
  * **`test.csv`** & **`train.csv`**: Testing and training datasets.
  * **`tingus.py`**: Python script for auxiliary functions.
  * **`catboost_info/`**: Local directory for CatBoost execution logs.
* **`catboost_info/`**: Root directory generated by CatBoost containing training logs, metrics, and execution details (`learn/`, `test/`, `tmp/`, `catboost_training.json`, `learn_error.tsv`, `test_error.tsv`, `time_left.tsv`).
* **`ChurnModel_corrigido.ipynb`**: Revised and corrected version of the main modeling notebook, located at the root of the project.

## 🛠️ Technologies Used
* **Language**: Python
* **Environment**: Jupyter Notebook
* **Machine Learning**: CatBoost
* **Data Manipulation**: Pandas / NumPy

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone [https://github.com/Rafaration/bank-churn-prediction.git](https://github.com/Rafaration/bank-churn-prediction.git)
   ```

2. Install the required dependencies (a virtual environment is recommended):
   ```bash
   pip install pandas numpy catboost jupyter
   ```

3. Open and run the corrected notebook:
   ```bash
   jupyter notebook ChurnModel_corrigido.ipynb
   ```
